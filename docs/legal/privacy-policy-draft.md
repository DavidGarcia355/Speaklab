# Privacy Policy Draft

Draft for legal review - not legal advice and not ready for publication without review.

## Overview

Habla is a classroom tool for language speaking assignments. This draft describes current repository behavior and uses placeholders where business or legal details must be supplied.

## Information Collected

Habla may process teacher names and emails from sign-in, student names and emails, class names, roster membership, assignments and instructions, uploaded attachments, audio recordings, submission timestamps, grades, rubric scores, written feedback, support/contact messages, activity logs, IP-address based rate-limit keys, and cookies/session data.

## Educational Use

Habla uses student information to provide the classroom speaking-assignment workflow requested by teachers and schools: collecting recordings, associating them with signed-in students, enabling teacher review, and showing grades/feedback.

## Audio Recordings

Student audio is uploaded to access-controlled storage and retrieved through teacher-authorized playback routes. Production storage configuration must be verified before publication or district onboarding.

## Service Providers

Habla uses service providers listed in `docs/subprocessors.md`. Provider regions, contractual terms, DPAs, and retention must be verified before signing district agreements.

## Advertising And Sale Of Student Data

The repository does not include advertising code or code that sells student data. Any policy statement should be reviewed by counsel before publication.

## AI

The repository contains an experimental AI-grading prototype. It is disabled by default and should not be used with student data unless separately reviewed, documented, and approved.

## Retention And Deletion

Implemented retention is described in `docs/data-retention-and-deletion.md`. Some areas require decisions, including account deletion, activity-log retention, support-message retention, provider backups, and district termination procedures.

## School Control And Requests

Schools may request access, correction, export, or deletion through: `[district data request contact]`. Parent and eligible-student requests should be routed through the school unless Habla receives other legally reviewed instructions.

## Security

Implemented controls include OAuth sign-in, teacher role checks, class ownership checks, private audio upload, protected playback routes, validation, rate limiting when configured, security headers, and cron authorization. No statement in this draft should be read as a guarantee of security.

## Children

Habla is intended for school-authorized educational use. COPPA and state student-privacy obligations require legal review and district-specific instructions.
