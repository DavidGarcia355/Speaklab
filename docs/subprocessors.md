# Subprocessors

This list is based only on integrations present in the repository. Contractual terms, DPAs, regions, and provider retention must be verified manually.

| Service | Purpose | Data possibly sent | Student data possible | Required | Env/config | Evidence | Unknowns |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Google OAuth / Google Workspace | Sign-in. | Name, email, OAuth identifiers/session profile. | Student email/name when students sign in. | Required in base auth setup. | `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET` | `auth.ts`, `app/api/auth/[...nextauth]/route.ts` | District OAuth approval, Google Workspace controls, contractual terms. |
| Microsoft OAuth / Azure AD | Optional sign-in. | Name, email, OAuth identifiers/session profile. | Student email/name if enabled. | Optional. | `AUTH_MICROSOFT_ID`, `AUTH_MICROSOFT_SECRET`, `AUTH_MICROSOFT_TENANT_ID` | `auth.ts` | Tenant restrictions, district approval, DPA. |
| Turso/libSQL | Application database. | Users, classes, assignments, submissions metadata, grades, feedback, roster, activity logs. | Yes. | Production database required. | `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN` | `lib/db.ts` | Region, backup retention, DPA, encryption details. |
| Vercel | Hosting/serverless runtime and cron. | Requests, logs, env vars, server-rendered app data. | Possible through request metadata/logs. | Deployment provider. | Vercel project config, `vercel.json` | `next.config.ts`, `vercel.json` | Region, access controls, logs retention, DPA. |
| Vercel AI Gateway | Optional routing layer between Habla and configured AI providers. | The same student audio, transcript, assignment, rubric, and result traffic sent to the selected provider when Gateway routing is enabled. | Yes. | Optional; currently the Vercel deployment default when AI is approved. | `AI_GATEWAY_ENABLED`, Vercel OIDC or `AI_GATEWAY_API_KEY` | `lib/ai/config.ts`, `lib/ai/providers.ts` | Gateway logs/retention, region, provider routing, DPA, and whether observability stores content. |
| Vercel Blob | Private storage for student audio and assignment attachments; the legacy public store is used only as a migration source pending verified cleanup. | Audio recordings, attachments, object paths. | Yes for audio; attachments may include educational content. | Required for production uploads. | Runtime: linked private store plus `AUDIO_BLOB_STORE_ID` and project OIDC. Migration only: `AUDIO_READ_WRITE_TOKEN`, `BLOB_READ_WRITE_TOKEN`. | `lib/audio-blob.ts`, `lib/audio-storage.ts`, `lib/attachment-storage.ts`, protected audio/attachment routes, `scripts/migrate-public-audio-to-private.mjs` | Region, DPA, backup/restore validation, deletion semantics, and proof that migration cleanup left no in-scope public objects. Static migration tokens must be removed/revoked after use. |
| Upstash Redis | Rate limiting. | Rate-limit keys: IP address or user email depending route. | Student email for submission rate limits. | Required for production rate-limited routes. | `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | `lib/rate-limit.ts` | Region, retention, DPA. |
| Resend | Email notifications. | Teacher email, feedback/contact message details. | Not intended for student submissions. | Optional. | `RESEND_API_KEY` | `lib/email.ts` | Sender domain, DPA, retention. |
| Discord webhooks | Generic founder event notifications. | Event label only; current payloads omit account, contact, school, message, and student identifiers. | No student submission content. | Optional. | `DISCORD_WEBHOOK_URL` | `lib/activity.ts` | Workspace access and retention; re-review before adding any payload fields. |
| OpenAI | Optional transcription and grading using the exact configured model IDs. The repository candidate pins `gpt-4o-mini-transcribe`, `gpt-5-nano`, and `gpt-5-mini` escalation, but those IDs still require evaluation and approval. | Student audio, transcripts, rubric, assignment instructions, and generated grading output if enabled. | Yes. | Disabled by the versioned production gate until reviewed. | `AI_GRADING_ENABLED`, provider/model variables, `OPENAI_API_KEY` or Vercel AI Gateway | AI routes, `lib/ai/providers.ts`, `lib/grading/providers.ts` | Contract, data-use settings, retention mode, DPA, region, quality/cost evaluation, and the exact approved model snapshots. |
| Google Gemini | Optional provider-neutral grading and direct-audio path when explicitly configured. | Transcript or student audio, rubric, assignment instructions, and generated grading output. | Yes. | Not used by the pinned transcription-first OpenAI candidate; requires a separate review before configuration. | `GRADING_DEFAULT_PROVIDER`, `GRADING_ESCALATION_PROVIDER`, `GRADING_AUDIO_STRATEGY`, `GRADING_AUDIO_MODEL`, `GOOGLE_API_KEY` | `lib/grading/config.ts`, `lib/grading/providers.ts`, `lib/grading/audio-pipeline.ts` | Contract, training/data-use controls, retention, DPA, region, model IDs, and direct-audio authorization. |
| OpenRouter | Optional routing/provider path for text grading when explicitly configured. | Transcript, rubric, assignment instructions, and generated grading output. | Yes. | Not used by the pinned OpenAI candidate; requires separate review. | provider/model variables and `OPENROUTER_API_KEY` | `lib/grading/config.ts`, `lib/grading/providers.ts` | Downstream provider identity, routing, logs, retention, region, DPA, and exact models. |
| Ollama or external model host | Alternative grading path (not the current default) that keeps transcripts off OpenAI by running grading on a self-hosted model. | Transcript, rubric, assignment instructions. | Yes if enabled via `AI_GRADING_PROVIDER=ollama`. | Optional; requires provisioning a persistent host (not usable on Vercel serverless). | `AI_GRADING_ENABLED`, `AI_GRADING_PROVIDER`, `OLLAMA_URL`, `OLLAMA_MODEL` | AI route | Host identity, region, logging, retention, access controls. |
